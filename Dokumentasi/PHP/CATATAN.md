Dokumentasi PHP (Web)
=====================

Cara menjalankan:
1. Install/aktifkan XAMPP atau Laragon (yang menyediakan PHP).
2. Letakkan folder PHP di htdocs (misal C:\xampp\htdocs\TP1DPBO\PHP) atau
   langsung jalankan dari folder PHP:
     php -S localhost:8000
3. Buka browser ke http://localhost:8000 (atau http://localhost/TP1DPBO/PHP/index.php)
4. Screenshot hasil di sini:
   - Form Tambah Film + tabel daftar film
   - Hasil pencarian (Cari)
   - Form Update saat tombol Update diklik
   - Data setelah Hapus

Catatan: penyimpanan memakai $_SESSION (tanpa database).
